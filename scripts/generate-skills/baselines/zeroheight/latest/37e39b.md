## Cas d'usage

Les Software icons doivent être utilisées uniquement pour représenter un logiciel Lucca :

1. Dans le catalogue de logiciels.
2. Pour naviguer vers un des logiciels (depuis la page d’accueil ou le menu de logiciels).
3. Pour représenter un logiciel au sein d'un autre logiciel Lucca (par exemple, dans l’Assistant Paie).

### Wrapper

Les Software icons peuvent être affichées sous forme de wrapper, par exemple dans les tableaux, pour afficher une liste de logiciels. Un nombre maximal peut être défini, les logiciels masqués restent accessibles via un Popover.

Un Tooltip s'affiche au survol des icônes pour indiquer le nom du logiciel.

# Changelog

## Software icon changelog

### 21.3.1

#### Added

- `salesforce` value for the `icon` input.

### 21.3.0

#### Added

- `SOFTWARE_ICON` and `SOFTWARE_ICON_SIZE` constants, together with the `SoftwareIcon` and `SoftwareIconSize` types, are now publicly exported and used to type the `icon` and `size` inputs.

### 21.2.3

#### Added

- `iconAlt` input to provide an alternative text for the icon.
- `withTooltip` input to reveal the icon label in a tooltip.
- `LU_SOFTWARE_ICON_WRAPPER` injection token, set when the icon is rendered inside a `lu-software-icon-wrapper`.

### 21.2.2

#### Added

- New icons in the available software list.

### 21.1.4

#### Added

- New product icons in the available software list.

### 21.1.1

#### Added

- Face and mood icons.

#### Fixed

- Naming of some icons.

### 21.1.0

#### Added

- `lu-software-icon` component (`softwareIcon`) with the required `icon` input plus `size` and `disabled`.
