## Définition

Le pattern d’Impersonation permet à un utilisateur d’accéder au contenu d’une page d’un collaborateur dans un but de consultation ou pour y effectuer des actions. Cela évite la création de pages ou de vues pour un besoin d'administration.

L’utilisateur disposant des droits d'impersonation, intervient directement dans le contexte du collaborateur sélectionné, tout en garantissant une traçabilité complète : chaque opération est enregistrée et historisée sous l'identité de l’utilisateur connecté et non celle du collaborateur sélectionné. Ainsi, chaque action est attribuable au bon utilisateur dans l’historique des actions.

## Comportement

### État par défaut

Par défaut, sur une interface où la fonctionnalité d’impersonation est disponible, le contenu présente les données du **compte du collaborateur connecté**.

Le composant affiche donc l’Avatar, le prénom et le nom du collaborateur connecté.

<design>

**🖼️ Behavior - Default**

**🖼️ Behavior - Default**

### Collaborateur sélectionné

Lorsqu’un autre collaborateur est sélectionné, le contenu du composant est donc **remplacé par l’Avatar, le prénom ainsi que le nom de ce collaborateur**.

À ce contenu vient s’ajouter le composant Clear, permettant de revenir à l’état par défaut.

Pour appuyer visuellement l’aspect actif de l’impersonation, le composant se voit appliquer la couleur `product`.

## Règles d’utilisation

### Positionnement dans la page

Par garder une cohérence entre les logiciels, le composant d’Impersonation doit se situer toujours au même endroit : **à droite du titre de la page**.

| Rule | Image | Caption | Description |
| :--- | :--- | :--- | :--- |
| Do |  |   | Positionnons le composant d’Impersonation directement après le titre de la page.  |

### Impact sur le titre des pages

L’utilisation de l’Impersonation n’a aucun impact sur le titre des pages. De manière générale, nous n’utilisons pas des titres comme “Mes formations” ou “Mes dépenses”. Privilégions l’utilisation d’un titre de page sans possessif.

| Rule | Image | Caption | Description |
| :--- | :--- | :--- | :--- |
| Don't |  |   | N’ajoutons pas la préposition “de” à la fin du titre. Le titre ne doit pas être lu comme une phrase se terminant par le composant d’impersonation. |
| Don't |  |   | Ne changeons pas le titre de la page lorsque l’Impersonation n’est pas disponible. N’ajoutons pas “Mes” devant le titre. |

# Angular

## Impersonation Angular `v21.3`

Component selector : `lu-impersonation`

```ts
import { ImpersonationComponent } from '@lucca-front/ng/impersonation';
```

[Basic](https://lucca-front.lucca.io/master/storybook/iframe.html?id=documentation-navigation-impersonation-angular-basic--basic)

### Imports et configuration

Pour utiliser le composant `lu-impersonation`, vous devez l'importer dans votre composant :

```tsx
import { ImpersonationComponent } from '@lucca-front/ng/impersonation';

@Component({
  selector: 'my-component',
  imports: [ImpersonationComponent],
  template: `...`
})
export class MyComponent {
  // ...
}
```

### Utilisation basique

Le composant affiche un bouton avec le profil utilisateur actuellement actif. En cliquant dessus, une liste déroulante s'ouvre pour sélectionner un autre utilisateur.

```html
<lu-impersonation [(selectedUser)]="selectedUser" />
```

### Propriétés et sortie

#### Entrées (inputs)

- **`selectedUser`** (model `ILuUser`): L'utilisateur actuellement sélectionné pour l'impersonification. Peut être modifié via `[(selectedUser)]` ou `[selectedUser]`. **Attention: la valeur par défaut doit être l'utilisateur actuellement connecté, aucune valeur nullable n'est acceptée**

- **`enableFormerEmployees`** (boolean, défaut: `false`): Permet d'inclure les anciens employés dans la liste de sélection lorsque la valeur est définie à `true`.

- **`intl`** (object): Les traductions du composant. Accepte les clés suivantes:
  - `switchProfile`: Texte du bouton principal (par défaut : "Changer de profil")
  - `a11yNavigationDescription`: Description pour l'accessibilité (par défaut : "Utiliser les flèches haut/bas pour naviguer")
  - `clear`: Libellé du bouton d'effacement (par défaut : "Effacer")
  - Ainsi que toutes les traductions du sélecteur utilisateur (`luCoreSelectUserTranslations`)

#### Sorties (outputs)

- **`clear`**: Émis lorsque l'utilisateur clique sur le bouton d'effacement pour réinitialiser la sélection, il est recommandé de s'en servir pour effectuer un reset côté BU, en remplaçant `selectedUser` par l'utilisateur en cours.

### Personnalisation des traductions

Si vous souhaitez personnaliser les traductions, vous pouvez fournir vos propres valeurs :

```tsx
import { ImpersonationComponent } from '@lucca-front/ng/impersonation';
import { LU_IMPERSONATION_TRANSLATIONS } from '@lucca-front/ng/impersonation';

@Component({
  selector: 'app-user-menu',
  imports: [ImpersonationComponent],
  providers: [
    {
      provide: LU_IMPERSONATION_TRANSLATIONS,
      useValue: {
        switchProfile: 'Sélectionner un utilisateur',
        a11yNavigationDescription: 'Naviguer avec les flèches',
        clear: 'Réinitialiser',
        // + autres traductions du sélecteur utilisateur
      }
    }
  ],
  template: `<lu-impersonation [(selectedUser)]="user" />`
})
export class MyComponent {
  // ...
}
```

# Changelog

## Impersonation changelog

### 22.1.1

#### Deprecated

- `operationIds` and `appInstanceId` inputs — use `uniqueOperationIds` instead.

### 22.1.0

#### Added

- `operationIds`, `uniqueOperationIds` and `appInstanceId` inputs to restrict the selectable users to the ones reachable through these operations.

### 21.3.0

#### Added

- `lu-impersonation` component (`impersonation`) to let an administrator browse the application as another user.
- `selectedUser` model, plus the `enableFormerEmployees`, `clear` and `intl` inputs.
