| Input                   | Type                                                                                                            | Default     | Description                                                                                        |
| ----------------------- | --------------------------------------------------------------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------- |
| `prButton` / `luButton` | `''` \| `'outlined'` \| `'AI'` \| `'AI-invert'` \| `'ghost'` \| `'ghost-invert'` \| `'text'` \| `'text-invert'` | `''`        | Visual variant of the button.                                                                      |
| `size`                  | `'M'` \| `'S'` \| `'XS'`                                                                                        | —           | Size of the button. Medium style applies when unset.                                               |
| `palette`               | `'success'` \| `'warning'` \| `'error'` \| `'product'` \| `'neutral'` \| `'none'` \| `'brand'`                  | `'none'`    | Color palette applied to the button.                                                               |
| `state`                 | `'default'` \| `'loading'` \| `'error'` \| `'success'`                                                          | `'default'` | `loading` disables the button; `error` plays a shake animation.                                    |
| `disabled`              | `boolean`                                                                                                       | `false`     | Disables the button. Also applied when `state` is `loading`.                                       |
| `critical`              | `boolean`                                                                                                       | `false`     | Signals a significant or irreversible action on hover and focus. Only with `outlined` and `ghost`. |
| `disclosure`            | `boolean`                                                                                                       | `false`     | Indicates that the button opens a menu.                                                            |
| `block`                 | `boolean`                                                                                                       | `false`     | Makes the button take the full width of its container.                                             |
| ~~`delete`~~            | `boolean`                                                                                                       | `false`     | **Deprecated** — use `critical`.                                                                   |
